Orange — RAG Banking Assistant

Ask a question. This runs a real retrieval pipeline in your browser — TF‑IDF similarity search over the same 26-document banking knowledge base used in the full project — then composes a grounded answer, or honestly refuses if the knowledge base doesn't cover it.

Customer inquiry
Retrieval here uses TF‑IDF + cosine similarity for a dependency-free, in-browser demo. The production pipeline (see RAG_Banking_Chatbot.ipynb) swaps this for real sentence-transformer embeddings and an open-source LLM (TinyLlama) via LlamaIndex — same architecture, same grounding strategy, higher-fidelity retrieval and generation.
